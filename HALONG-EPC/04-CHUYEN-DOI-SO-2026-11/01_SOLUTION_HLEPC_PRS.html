Hệ thống tự phát triển · 10 phân hệ nghiệp vụ

Bộ sản phẩm dùng riêng cho HLEPC — không phụ thuộc nền tảng bên ngoài, mở rộng theo đặc thù chế tạo cơ khí xuất khẩu.

Nguyên tắc thiết kế

  • Microservices · mỗi phân hệ 1 service độc lập, deploy riêng
  • API-first · REST + GraphQL nội bộ, event bus cho luồng async
  • SSO duy nhất · 1 tài khoản dùng cho 10 phân hệ + mobile
  • Master data tập trung · KH/NCC/VT/NV/Dự án/BOM dùng chung
  • Web + Mobile + Tablet xưởng · cùng API, UI theo ngữ cảnh
  • Mã nguồn HLEPC sở hữu · không vendor lock-in, không subscription
  • Đa ngôn ngữ · Anh/Việt/Nhật cho dossier xuất khẩu
L1 · UI
Dashboard web (SPA) · Mobile app thợ xưởng · Tablet QC · Customer portal · Big screen SOC
L2 · App
10 microservice nghiệp vụ · self-built · stateless · container hoá
L3 · Bus
API Gateway · Event bus (publish/subscribe) · Workflow engine
L4 · Data
RDBMS chính · Time-series DB (IoT) · Document/object store · Search index
L5 · IAM
SSO · RBAC · Audit log · Chữ ký số · Mã hoá at-rest + in-transit
L6 · Infra
On-prem private cloud · K8s cluster · CI/CD · GitOps · Backup + DR

10 phân hệ · tính năng cốt lõi

Đánh số 1 → 10 theo đúng thứ tự triển khai (build order) — production-first, khớp 1:1 với Gantt bên dưới. Nhóm theo 3 Phase: lõi sản xuất trước, cung ứng & con người, rồi thiết kế · thiết bị · tài chính · khách hàng.

Giả định & rủi ro

  • Không có Tech Lead, SA, DevOps, UI/UX, Mobile, IoT hay AI riêng, nên 3 dev phải tự gánh kiến trúc, CI/CD và app xưởng. Riêng nền tảng mất 3 tháng (kế hoạch: 2 tháng).
  • PPM làm trước MES vì MES cần dự án/WBS làm dữ liệu gốc, mà team nhỏ không làm song song được.
  • IoT máy (EAM) và Digital Twin hoãn hoặc thuê ngoài, không nằm trong 45 tháng này.
  • Tỷ lệ 4 Test / 3 Dev là dư test. Nếu chuyển 1 Test sang Dev (4 Dev · 3 BA · 3 Test), tổng ước rút còn khoảng 36–38 tháng.
  • Ước lượng thô ±15%, cần re-plan sau khi chốt spec chi tiết từng phân hệ.
